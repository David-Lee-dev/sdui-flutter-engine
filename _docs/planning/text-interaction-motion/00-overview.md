# 텍스트 · 상호작용 모션 — 범위 카드

작성 2026-11-09, 범위 사용자 승인 2026-11-09. 기준 엔진 0.25.0. 근거 조사: [research.md](research.md).
이 문서는 기획이다. 구현을 약속하는 규범은 결정이 끝난 뒤 `_docs/spec/`에 따로 쓴다.

## 목적

템플릿이 `_motion` · `_morph`만으로 만들기 어려운 두 종류의 모던 UI 애니메이션을 엔진이 직접 제공한다.

1. 텍스트를 글자·단어·줄 단위로 움직이는 효과와, 숫자가 바뀔 때의 효과(카운트업, 슬롯머신).
2. 버튼 상호작용의 상태 시퀀스(누름 → 로딩 → 완료 체크 → 원래 내용)를 끝까지 템플릿으로 표현하는 데 빠진 조각.

## 범위

### 다루는 것

**A. 텍스트 모션** — `text`, `rich_text`에만 붙는 `_motion` 프리셋으로 제공한다(D1).

| 묶음 | 효과 | 단위 | 비고 |
|---|---|---|---|
| A1 등장·퇴장 | `rise`(아래에서 올라옴), `fade`, `blur`(블러 풀림), `pop`(작게→크게), `typewriter`, `scramble`(무작위 글자 → 정답) | 글자(grapheme) · 단어 · 줄 | 시차(stagger), 기존 `_motion` 스케줄 파라미터 공유: `delay`, `duration`, `curve`, `trigger`, `on: enter/exit/both`, `start`, 축소 모션 |
| A2 숫자 변화 | `count`(값이 이전 값에서 새 값까지 연속 증가·감소), `roll`(자릿수마다 굴러서 새 숫자에 멈춤) | 숫자 문자열 | `roll`은 숫자 0–9 자리만 굴리고 쉼표·단위·한글·영문은 굴리지 않는다. 숫자가 아닌 글자에는 도입하지 않는다 |

필수 성질:

- 줄바꿈은 원래 텍스트와 같아야 한다. 한국어는 어절 단위 줄바꿈을 지킨다. 글자마다 위젯을 만들지 않고 한 문단 배치 안에서 그린다.
- 이모지·결합 문자는 grapheme 단위로 다룬다.
- 접근성 라벨은 애니메이션 도중에도 전체 텍스트(숫자는 최종 값)다.
- 축소 모션이면 끝 상태를 바로 보인다(기존 `_motion` 규칙과 같다).
- `rich_text`의 span 스타일은 유지한다.

**B. 상호작용**

| 항목 | 내용 | 상태 |
|---|---|---|
| B0 로딩 스피너 | `loading_indicator` 위젯이 `loading_animation_widget` 패키지로 21종 제공(`staggered_dots_wave`, `three_arched_circle`, `ink_drop` 등) | **이미 있음, 작업 없음** |
| B1 SVG 선 그리기 | 임의 SVG를 선으로 그려 나가는 위젯. 그리는 진행도를 `_motion` · `_morph`로 움직인다. 체크 · 엑스 · 원 테두리는 이름으로 쓰는 기본 경로로 함께 제공한다(가정). 입력은 SVG 문서(D5) | 신규 |
| B2 `wait` 명령 | 액션 순차 흐름에서 지정 시간 기다린다. "완료 → N초 뒤 원래대로"에 필요하다. 지금 액션 문법에는 지연 수단이 없다 | 신규 |
| B3 진행 링 끝 모양 | `circular_progress_indicator`에 `stroke_cap`(둥근 끝) 속성 추가. 링 자체는 `value` + `_morph`로 이미 된다 | 작은 추가 |

버튼 시퀀스의 단계 전환(크로스페이드, 크기 변화, 단계별 등장·퇴장 효과)은 `switch` + `_presence` + `_motion`으로 이미 된다. 이 기획은 그 위에 빠진 B1 · B2와, 복귀할 때 글자별 효과를 주는 A1을 더한다.

### 다루지 않는 것

- Lottie 플레이어, 하트 버스트 같은 파티클 효과(사용자 결정 2026-11-09: 작업 범위에서 제외).
- 스크롤 연동 애니메이션, 리스트 재정렬 이동 애니메이션.

## 단계와 완료 기준

1. 기획 결정 — 아래 Q1–Q5를 한 번에 하나씩 정한다. 완료: 열린 결정 없음, 사용자 범위 승인.
2. 구현 명세 — `_docs/spec/`에 기능별 명세(동작 · 경계 · 오류 · 수용 기준 · 테스트). 완료: 명세 승인.
3. 구현 — 기본 순서: B2 `wait` + B3 `stroke_cap` → A1 등장·퇴장 → A2 숫자 → B1 SVG 선 그리기. 각 기능은 새 `_requires` capability로 열어, 이전 엔진이 새 템플릿을 컴파일에서 거부하게 한다. 완료: 공개 경계 테스트 통과, `docs/` 문서, CHANGELOG, 버전 올림.

## 결정

| ID | 결정 | 근거 |
|---|---|---|
| D1 | 텍스트 효과(A1 · A2)는 `_motion` 프리셋으로 선언한다. 예: `_motion: { type: text_rise, unit: grapheme, stagger: 38 }`. 텍스트 프리셋을 `text` · `rich_text`가 아닌 노드에 붙이면 컴파일 오류. `_motion`은 위젯을 바깥에서 감싸는 구조라 글자에 닿지 못하므로, 텍스트 위젯이 효과를 받아 직접 그리게 엔진을 고친다 | 사용자 결정 2026-11-09. 기존 프리셋 이름 · `trigger` · `on: exit` · 스케줄 파라미터를 그대로 재사용해 배울 것이 가장 적다. 진행도를 `_morph`로 직접 구동하는 속성안은 채택하지 않음 |
| D2 | 숫자 효과(`text_count` · `text_roll`)는 처음 화면에 나올 때 멈춘 채 현재 값을 보이고, 표시 값이 바뀔 때만 이전 값에서 새 값으로 재생한다. `from`을 지정하면 처음에도 `from`에서 현재 값으로 재생한다(예: 보상 화면 `from: 0`). 일반 `_motion`의 "생길 때 재생" 규칙과 다른 예외이며, 숫자 프리셋에만 적용한다 | 사용자 결정 2026-11-09. 잔액처럼 늘 보이는 숫자가 화면에 들어올 때마다 0부터 다시 올라가지 않게 하고, 등장 연출이 필요한 곳만 `from` 한 줄로 연다
| D3 | 숫자 효과가 재생 중일 때 표시 값이 다시 바뀌면, 처음부터 다시 재생하지 않고 지금 보이는 위치에서 새 값으로 이어간다. spring 곡선이면 현재 속도도 이어진다. `text_roll`은 각 자릿수 띠가 현재 위치에서 새 숫자로 이어 굴러간다 | 사용자 결정 2026-11-09. 값이 연달아 바뀌어도(연속 적립 등) 숫자가 뒤로 튀지 않는다. 기존 `_morph`의 재목표(retarget) 동작과 같다 |
| D4 | B1은 정해진 마크가 아니라 임의 SVG를 그릴 수 있게 한다. 다양한 SVG를 지원하는 것이 엔진의 역할이다 | 사용자 결정 2026-11-09. 체크 · 엑스만 고정하면 화살표 · 윤곽 · 일러스트 선 등 새 연출마다 엔진 배포가 필요해진다 |
| D5 | B1 입력은 SVG 문서다. 디자인 도구에서 내보낸 `<svg>` 마크업을 템플릿에 그대로 넣는다. 지원 요소 부분집합(`path` · `line` · `polyline` · `polygon` · `circle` · `ellipse` · `rect` · `g`, `transform`, `viewBox`, stroke · fill 속성)을 문서 순서대로 그린다. 미지원 요소 처리, 크기 맞춤, 오류 처리 규칙은 구현 명세에서 정한다 | 사용자 결정 2026-11-09. 경로 좌표를 옮겨 적는 수고 없이 디자이너 산출물을 그대로 쓴다. 엔진 파싱 작업이 커지는 비용을 받아들인다 |
| D6 | `wait` 도중 화면을 떠나거나 액션을 가진 위젯이 사라지면 남은 흐름을 취소한다. 위젯이 사라질 때 액션 흐름을 정리하는 기존 수명 규칙을 따른다 | 사용자 결정 2026-11-09. 사라진 위젯의 상태를 되돌릴 이유가 없고, 화면 밖에서 상태를 고치다 생기는 오류를 막는다 |

## 열린 결정

없음. 다음 단계는 `_docs/spec/`의 구현 명세다.

## 가정 (되돌리기 쉬워 기본안으로 둔 것)

- capability 이름은 구현 명세에서 정한다(예: `text_motion_v1`, `wait_v1`).
- 효과 이름은 위 표의 영문 이름을 출발점으로 한다.
- 성능 목표는 기기 profile 모드 실측으로 판단한다(비율이 아닌 체감 가능한 절대 수치).
- B1의 체크 · 엑스 · 원 테두리는 이름으로 부르는 기본 경로로 제공한다.

## 용어

| 용어 | 뜻 |
|---|---|
| grapheme | 사용자가 한 글자로 보는 단위. 이모지·결합 문자를 한 덩어리로 센다 |
| stagger | 단위마다 시작을 조금씩 늦추는 시차 |
| 상태 시퀀스 | 한 버튼이 idle → loading → done → idle처럼 단계를 거치는 연출 |
| 축소 모션 | 기기의 «동작 줄이기» 설정(`MediaQuery.disableAnimations`) |
