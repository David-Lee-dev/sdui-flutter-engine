# 3D 아바타 에셋 제작 가이드 (외주 규격서)

대상: sdui_engine 0.29.0의 `model_3d` 위젯과 sdui_model_filament 0.3.0 렌더러.
요구사항(2026-11-15 사용자 답변): 동물 마스코트 **1종**, **단색 위주 로우폴리**, 사용자가 **옷(상의·하의·신발)·헤어·소품(모자·안경·가방·손에 든 물건)**을 바꿈, **외주 3D 아티스트**가 Blender로 제작, **작게 시작**한 뒤 확장.

## 1. 결과물 목록 (1차)

| 파일 | 내용 | 수량 |
|---|---|---|
| `character.glb` | 뼈대, 부위별 몸, 얼굴 표정, **모든 옷·헤어 변형**, 소켓, 애니메이션 | 1 |
| `prop_<종류>_<이름>.glb` | 모자·안경·가방·손에 든 물건. 휘지 않는 소품, 파일 하나에 하나 | 8~10 (모자 3, 안경 2, 가방 2, 손 물건 2) |
| `planet.glb` | 캐릭터가 서는 작은 행성과 장식 | 1 |
| `thumb_<아이템 id>.webp` | 상점 목록용 썸네일 (아이템마다 1장, 색 변형은 색마다) | 아이템 수만큼 |
| `.blend` 원본 + 명명표 | 모든 원본 파일과 아래 이름 규칙을 채운 표 | — |

1차 옷·헤어 변형은 상의 3, 하의 3, 신발 2, 헤어 3개를 권장합니다.

## 2. 왜 이렇게 나누는가

- **옷과 헤어는 몸을 따라 휘어야 하므로 캐릭터 파일 안에** 넣습니다. 엔진은 따로 받은 옷을 캐릭터 뼈대에 다시 묶을 수 없습니다(thermion에 `attachSkin`이 없음). 옷은 미리 넣어 두고 보이기/숨기기(`outfit.show`/`hide`)로 갈아입힙니다.
- **소품은 휘지 않으므로 별도 파일**로 만들고 소켓에 붙입니다(`outfit.attach`). 개수 제한이 사실상 없고, 나중에 CDN에 추가만 하면 됩니다.
- **행성은 별도 파일**로 둡니다. 캐릭터를 바꿔도 다시 받지 않고, 행성만 교체할 수 있습니다(`scene`).

## 3. 공통 규칙 (모든 파일)

1. **단위는 미터, +Y 위, 캐릭터 정면은 +Z.** Blender 기본 glTF 내보내기 설정이 이와 같습니다.
2. **모든 오브젝트의 스케일을 적용합니다(Ctrl+A → Scale).** 특히 아르마추어의 오브젝트 스케일은 1이어야 합니다. 아르마추어에 0.01이나 100 같은 스케일이 남으면 소품이 그 배율로 붙습니다(실측에서 모자가 1/100로 붙은 사례).
3. **스키닝된 메시 오브젝트는 변환이 없어야 합니다**(위치 0, 회전 0, 스케일 1). 스키닝 메시 노드에 변환이 있으면 엔진의 크기 계산과 실제로 그려지는 크기가 어긋나 화면 밖으로 잘립니다(실측 사례).
4. **이름은 영문 소문자, 숫자, `_`만 씁니다.** 엔진은 노드·재질·클립·모프 이름으로 정확히 일치를 찾습니다. 공백과 대소문자 차이가 있으면 동작하지 않습니다.
5. **압축하지 않은 glTF Binary(.glb)로 내보냅니다.** Draco/meshopt 압축은 쓰지 않습니다. 렌더러가 경계를 계산하지 못해 예전 방식으로 대체되고, 프레이밍이 부정확해집니다.
6. 텍스처를 쓰면 1024px 이하로 하고, 전달 후 KTX2로 변환합니다(gltf-transform). 단색 스타일이면 텍스처 없이 재질 색만 써도 됩니다.

## 4. `character.glb` 상세

### 4.1 뼈대

- 뼈는 60개 이하로 합니다. 뼈 이름은 한 번 정하면 바꾸지 않습니다. 모든 옷·헤어·애니메이션이 이 이름에 묶입니다.
- 필수 뼈 이름(마스코트에 맞게 추가 가능): `root`, `hips`, `spine`, `chest`, `neck`, **`head`**, `upper_arm.l/r`, `lower_arm.l/r`, `hand.l/r`, `upper_leg.l/r`, `lower_leg.l/r`, `foot.l/r`, 그리고 꼬리·귀가 있으면 `tail_01…`, `ear.l/r`.
- `head`는 시선 기능(`look_at`)의 기본 뼈 이름이므로 이 이름을 그대로 씁니다.

### 4.2 몸

- 몸을 부위별 메시로 나눕니다: `body_head`, `body_torso`, `body_arms`, `body_legs`, `body_feet`, (`body_tail`).
- 옷이 덮는 부위는 그 옷을 입을 때 숨깁니다. 예를 들어 긴소매 상의를 입으면 `body_arms`를 숨깁니다. 움직일 때 몸이 옷을 뚫고 나오는 문제를 막기 위해서입니다. 어떤 옷이 어떤 부위를 숨기는지는 명명표에 적습니다.

### 4.3 옷·헤어 변형

- 변형 하나 = 메시 오브젝트 하나: `top_<이름>`, `bottom_<이름>`, `shoes_<이름>`, `hair_<이름>`.
- 모두 같은 아르마추어에 웨이트를 줍니다. 헤어는 `head` 뼈(및 머리카락 뼈)에만 웨이트를 줍니다.
- 기본으로 입은 변형 하나씩만 보이게 두고, 나머지는 숨긴 상태로 내보냅니다(Blender에서 렌더 비활성). 엔진에서 이름으로 켜고 끕니다.
- 메시 하나에 재질 하나를 권장합니다. 재질이 여러 개인 메시는 일부 기능에 제약이 생깁니다.

### 4.4 색 바꾸기

- 사용자가 색을 바꿀 수 있는 부분은 **재질을 따로** 씁니다: `mat_<아이템>_<부분>` (예: `mat_top_hoodie_main`, `mat_top_hoodie_string`).
- 단색 스타일이면 재질의 Base Color를 기본색으로 둡니다. 엔진은 이 색을 템플릿 색으로 바꿉니다. 텍스처가 있으면 텍스처에 곱해집니다.
- 피부(털) 색을 바꾸려면 `mat_body_fur` 하나로 몸 전체를 칠합니다.

### 4.5 얼굴 표정 (블렌드셰이프)

- 얼굴 메시(`body_head`)에 셰이프 키를 만듭니다: `smile`, `sad`, `angry`, `surprised`, **`blink`**.
- `blink`는 자동 깜박임의 기본 이름입니다. 두 눈을 동시에 감는 셰이프 하나로 만듭니다.
- 값 0이 무표정, 1이 최대 표정입니다.

### 4.6 소켓

- 소품이 붙을 자리에 빈 오브젝트(Empty)를 만들고 해당 뼈에 자식으로 붙입니다.
- 1차 소켓: `socket_head`(모자), `socket_face`(안경), `socket_back`(가방), `socket_hand_r`(손에 든 물건).
- 소켓의 스케일은 1, 축은 캐릭터 정면(+Z), 위(+Y)와 맞춥니다. 소켓 위치가 소품 원점이 놓일 자리입니다.

### 4.7 애니메이션 클립

- 클립 이름은 영문 소문자: `idle`(반복), `walk`(반복), `run`(반복), `wave`, `happy`, `jump`, `sit`. 1차는 6~8개로 시작합니다.
- 반복 클립은 첫 프레임과 마지막 프레임이 이어지게 만듭니다.
- **겹치기용 클립**은 필요한 뼈만 움직입니다. 예를 들어 `wave_arm`은 오른팔 뼈만 키를 넣어, 걷기 위에 겹쳐 손을 흔들 수 있게 합니다(`layer`).
- 머리카락·꼬리·귀의 흔들림은 물리 대신 각 클립에 직접 키로 넣습니다.

## 5. 소품 `prop_<종류>_<이름>.glb`

- 원점(0,0,0)이 붙을 소켓 위치이고, 축도 소켓과 같습니다. 예: 모자는 원점이 머리 위 접점, 정면이 +Z.
- 캐릭터에 붙인 상태를 기준으로 크기를 맞춰 실제 미터 크기로 만듭니다(스케일 적용 필수).
- 색을 바꿀 부분은 캐릭터와 같은 규칙으로 재질을 나눕니다.
- 삼각형 2,000개 이하, 파일 200KB 이하를 권장합니다.

## 6. `planet.glb`

- 원점이 행성 중심입니다. 반지름을 명명표에 적습니다(예: 2m).
- 앱에서는 행성을 `position: [0, -반지름, 0]`에 두고, 캐릭터 발은 y=0에 섭니다. 걷는 장면은 캐릭터를 옮기지 않고 행성을 돌립니다(`spin`).
- 나무·집 같은 장식은 행성 파일 안에 함께 넣습니다(행성과 같이 돕니다).

## 7. 예산 (Galaxy Z Flip6 실측 기반 출발점)

| 항목 | 권장 |
|---|---|
| 동시에 보이는 캐릭터 삼각형 | 15,000 이하 |
| `character.glb` 전체(숨긴 변형 포함) | 40,000 삼각형, 5MB 이하 |
| 뼈 | 60개 이하 |
| 텍스처 | 1024px 이하 KTX2, 단색이면 없음 |
| 소품 | 2,000 삼각형, 200KB 이하 |
| 행성 | 10,000 삼각형, 1MB 이하 |

실측: 4.9만 삼각형 사람형 모델 1개가 60fps에서 CPU 70%, GPU 34%, 메모리는 3D 없을 때보다 약 +150MB였습니다. 숨긴 변형도 다운로드 용량과 메모리를 차지합니다. 그래서 캐릭터 파일 하나에 넣는 변형은 30개 정도까지를 권장합니다. 그 이상은 엔진 확장이 필요합니다.

## 8. 썸네일

- `.blend`에 고정된 썸네일 촬영 장면(카메라, 조명, 투명 배경)을 하나 두고, 스크립트로 아이템마다 렌더링합니다. 모든 썸네일의 각도와 조명이 같아야 합니다.
- 512×512 PNG로 렌더링해 WebP로 변환합니다. 파일 이름은 아이템 id와 같게 합니다.

## 9. 전달 전 검수 체크리스트

1. Khronos glTF Validator에서 오류 0개.
2. 모든 오브젝트 스케일 적용, 아르마추어 스케일 1, 스키닝 메시 노드 변환 없음.
3. 명명표의 이름(노드·재질·셰이프 키·클립·소켓)과 파일 안 이름이 정확히 일치.
4. 옷마다 숨겨야 할 몸 부위를 명명표에 기재했고, 모든 클립에서 몸이 옷을 뚫지 않음.
5. 소품을 각 소켓에 붙였을 때 제자리에 맞음(위치·방향·크기).
6. 반복 클립이 끊김 없이 이어짐.
7. 예산(7장) 안에 있음.

## 10. 앱 템플릿에서 쓰는 모습 (참고)

```yaml
_type: model_3d
src: /assets/character.glb
scene:
  - { src: /assets/planet.glb, position: [0, -2, 0], spin: { axis: x, speed: 20 } }
outfit:
  show: [top_hoodie, bottom_jeans, shoes_sneakers, hair_short]
  hide: [body_arms]
  colors: { mat_top_hoodie_main: '#3B82F6' }
  attach: { socket_head: /assets/prop_hat_cap.glb }
  transition: pop
morphs: { smile: 1 }
blink: true
look_at: { target: camera }
state: '${state}'
states:
  idle: { clip: idle, loop: true }
  walk: { clip: walk, loop: true }
shadow: contact
```

## 알려진 한계

- 툰 셰이딩과 외곽선은 지원하지 않습니다(2026-11-15 결정). 단색 로우폴리 스타일은 기본 조명으로 표현합니다.
- 따로 받은 옷을 뼈대에 붙이는 기능은 없습니다. 옷은 캐릭터 파일 안에 있어야 합니다.
- 캐릭터 종을 늘리면 그 종의 옷을 따로 만들어야 합니다(뼈대가 달라짐).
