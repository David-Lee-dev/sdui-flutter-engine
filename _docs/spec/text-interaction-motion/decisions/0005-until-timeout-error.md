# ADR-0005 · 시간 초과는 `WAIT_TIMEOUT` 오류다

- 상태: 승인 2026-11-09(사용자)
- 출처: 명세 제안 P-7
- 관련: TIM-01 WAIT-R10

## 맥락

조건 대기가 시간 안에 끝나지 않는 경우의 결과가 필요하다.

## 결정

`DriverError('WAIT_TIMEOUT')`로 끝나 `_error` 분기를 탄다. 분기가 없으면 기존 규칙대로 보고하고 흐름을 멈춘다.

## 근거

실패 분기를 기존 `_error` 문법으로 쓸 수 있다. 채택하지 않은 안: 성공 + `$data.timed_out`.
