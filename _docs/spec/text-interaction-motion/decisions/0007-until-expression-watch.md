# ADR-0007 · `until`은 식으로 넘겨 상태 변화를 감시한다

- 상태: 승인 2026-11-09(사용자)
- 출처: 명세 제안 P-9
- 관련: TIM-01 WAIT-R8

## 맥락

다른 파라미터는 실행 전에 한 번 계산되므로 조건을 다시 볼 수 없다.

## 결정

컴파일러는 `until`을 계산하지 않고 식으로 보관한다. 엔진 내부 타입 `DriverContext`에 식 감시 기능을 더해 식이 읽는 상태가 바뀔 때마다 다시 평가한다.

## 근거

`DriverContext`는 공개 API가 아니어서 앱·`external` 명령에 영향이 없다. 화면 반응형 갱신과 같은 감시 경로를 쓴다.
