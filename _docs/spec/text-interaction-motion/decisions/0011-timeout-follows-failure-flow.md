# ADR-0011 · 시간 초과 뒤 흐름은 기존 실패 규칙을 따른다

- 상태: 승인 2026-11-09(사용자)
- 대체: [ADR-0005](0005-until-timeout-error.md)의 "분기가 없으면 흐름을 멈춘다" 부분. `WAIT_TIMEOUT` 오류 코드와 `_error` 분기는 유지한다
- 관련: TIM-01 WAIT-R10, AC18, AC19

## 맥락

구조 검토에서 0.25.0 `ActionHost`는 명령이 실패해도 `_error`(또는 보고) 뒤 같은 흐름의 다음 batch를 이어 실행함을 확인했다(`_runFlow`, `_runCommand`). 명세 0.2는 시간 초과 뒤 흐름이 멈춘다고 적었고, 이를 지키려면 실행기에 흐름 중단 기능을 새로 넣어야 한다.

## 결정

`wait`의 시간 초과는 다른 명령 실패와 같다. `_error` 분기를 실행하거나 보고하고, `wait`의 `_then`은 건너뛰며, 다음 batch는 이어진다. 성공했을 때만 할 일은 `_then`에 둔다.

## 근거

최소 변경·기존 구조 유지(사용자 원칙 2026-11-09). 실행기를 바꾸지 않고 `net` 실패와 같은 문법으로 쓴다.
