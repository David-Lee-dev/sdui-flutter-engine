# Changelog

## 0.1.0

- `FilamentModelSource` / `FilamentModelController`: a `ModelSource` for the
  sdui_engine 0.15 `model` widget rendering with Filament through
  `thermion_flutter` 0.5, with a transparent background, the bundled studio
  IBL, drag and auto rotation in Flutter, clip playback with crossfade, and
  the `sdui_model_support` byte cache and debug overlay.
